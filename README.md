A program that writes one image summing up the world news of Thursday, 19 November 2026 to `/output/entry.png`. The image is a newspaper-style front page: six of the day's biggest stories, each with an illustration, a headline and a caption. All text on the poster was drawn with PIL so it stays crisp; the illustrations are AI-generated pictures with no text inside them.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
